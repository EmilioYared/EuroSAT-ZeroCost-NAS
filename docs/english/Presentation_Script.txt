 SLIDE 3 — OBJECTIVE                                 [0:45]
------------------------------------------------------------------
WHAT TO DO: Point to the two numbers on the left, then to the
objective on the right.

SAY:
"Let us start with the context. This project uses the EuroSAT
dataset: twenty-seven thousand satellite images, divided into ten
land-use classes, such as forest, river, or highway.
( / ) Designing a good network for such data is expensive. For
example, the first automatic search method used eight hundred
GPUs for twenty-eight days.
The problem is that every new idea requires a complete training
run, which takes time and energy.
( / ) Therefore, the objective of this project was to compare
three ways of building a classifier: first, designing a network
by hand; second, reusing a network pretrained on ImageNet; and
third, searching the architecture automatically, without
training."


------------------------------------------------------------------
 SLIDE 4 — METHOD: DATA AND THREE APPROACHES         [0:50]
------------------------------------------------------------------
WHAT TO DO: Point to the moving images first (each tile changes
to another example of its class), then to each card in turn.

SAY:
"Now, let us move to the method. Here, you can see examples of
the ten classes; the images change to show the variety inside
each class. All the models used exactly the same split of the
data, so the comparison is fair.
( / ) In the first approach, a simple network was improved one
factor at a time: its depth, its kernels, its optimiser, and its
data augmentation.
In the second approach, a ResNet-18 pretrained on ImageNet was
fine-tuned with five to one hundred percent of the data.
In the third approach, an algorithm called NASWOT scored one
thousand untrained networks in a few seconds, and only the best
one was trained."


------------------------------------------------------------------
 SLIDE 5 — METHOD: JUDGING A NETWORK WITHOUT TRAINING [0:55]
------------------------------------------------------------------
WHAT TO DO: Slow down here — this is your main idea. Point to
each numbered step, then to the animation on the right: it shows
the images, their binary codes and the kernel being filled in.

SAY:
"The key question is: how can we judge a network without training
it? The method works in three steps.
First, we take an untrained network and pass one batch of images
through it.
Second, we record which units of the network are active for each
image. This gives a binary code for every image, as shown in the
animation.
Third, we compare these codes. ( / ) If the codes are different,
the network can already separate the images, and it usually
trains well.
The kernel on the right counts how similar each pair of codes is,
and the score summarises it in a single number.
( / ) Before using this score, I validated it on NAS-Bench-201, a
benchmark of fifteen thousand networks whose accuracy is already
known."

 SLIDE 6 — RESULTS: HAND-DESIGN AND TRANSFER LEARNING [0:40]
------------------------------------------------------------------
WHAT TO DO: Point to the red line on the chart, then to each

SAY:
"Let us now look at the results, starting with the first two

The step-by-step study improved the hand-designed network from
ninety point two to ninety-seven percent.
However, the fine-tuned ResNet-18 obtained the highest accuracy:

( / ) Moreover, as shown by the red line on the chart, it still

------------------------------------------------------------------
 SLIDE 7 — RESULTS: NASWOT VERSUS FIVE SEARCH STRATEGIES [0:55]
------------------------------------------------------------------
WHAT TO DO: Explain the axes first; the curves draw themselves

SAY:
"Next, this chart compares NASWOT with five other search
strategies on the benchmark. The horizontal axis shows how many
networks were trained, and the vertical axis shows the accuracy
of the best network found. Each curve is the average of two
hundred runs.
( / ) First, the published results of NASWOT were reproduced

Second, without any training, NASWOT reached ninety-two point

Evolution with one hundred trained networks was better, at
ninety-four point one percent, but it was far more expensive.
( / ) Interestingly, the best strategy with a small budget was the
combination of both: NASWOT chooses the starting population, and
evolution improves it."

 SLIDE 8 — RESULTS: AUTOMATIC SEARCH ON EUROSAT      [0:40]

"After this validation, I applied the search to EuroSAT. One

The table compares my hand-designed network with the network
found by NASWOT. ( / ) The searched network was zero point seven

Furthermore, the search rediscovered the conclusions of my manual

POSSIBLE QUESTIONS AND SHORT ANSWERS
------------------------------------------------------------------
Q: What is neural architecture search?
A: "It is a method that designs the structure of a neural network
   automatically, instead of an engineer designing it by hand."

Q: Why does the score work without training?
A: "If an untrained network already gives different codes to
   different images, it can separate them easily. Such networks
   usually learn well during training."

Q: Why not always use ResNet-18, since it is the most accurate?
A: "Because it is nine times larger and slower. On limited
   hardware, for example on board a satellite, a smaller network
   can be the better choice."

Q: What is NAS-Bench-201?
A: "It is a public benchmark of fifteen thousand six hundred
   networks that have all been trained in advance. It allows us
   to compare search methods without training any network."

Q: Are your results reliable?
A: "The benchmark comparison was repeated two hundred times.
   However, the manual study used a single run per
   configuration, so only large differences are conclusive."
